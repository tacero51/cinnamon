## 秘密情報の保管場所

値は見たり出力したりせず、必要なときだけ既存のKeychain項目を使う。

| 用途 | Keychain上の項目 |
| --- | --- |
| Cloudflareデプロイ用APIトークン | `Cinnamon Cloudflare deploy token`（account: `codex`） |
| Workerのセッション署名鍵 | `Cinnamon session signing key`（account: `server`） |
| 家族ログイン | host: `cinnamon.tacero.workers.dev`、label: `Cinnamon family login` |

ログインパスワードを変更する場合は、Cloudflareの `LOGIN_PASSWORD` とPasswords / Keychainを同じ値へ更新し、`SESSION_SIGNING_KEY` も新しいランダム値へローテーションする。これにより全端末が再ログインになる。

### 1. 更新の競合対策（2026-09-06 実装）

- R2のETagを使った条件付き保存で、同時投稿・編集・削除による上書きを防ぐ。
- 一覧GETの `X-Entries-Version`（R2 ETag）を編集開始時に固定し、編集・削除のIf-Matchとして送る。版なしは428、古い版や保存中の競合は409で止める。

### 2. 子ども向けの最初の「好き発見」導線を作る

最初の機能は大規模なメーカーやポイント制ではなく、既存の記録から答えを見つけられる小さな分析画面がよい。

1. **完了（2026-09-07）**: 既存データだけで「★5だったもの」「点数順」「食べた場所ごとの点数」を見られる画面。
